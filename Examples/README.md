# Examples

Every design this library makes, as a PDF you can open before installing anything.

Generated by the library itself — `WRITE_EXAMPLES=1 swift test --filter ExampleTests` — so none of them can drift from what the code produces. All from the same one-page résumé, so the differences are the design's.

## Business cards

## Designs written as JSON

A `Blueprint` is a design as data — no Swift, no recompile. Every design above *is* one: a JSON file in the package's `Resources/Designs/`, rendered under designs/.

Plus [entry-cards](blueprints/entry-cards.pdf) — the one ornament no starting point uses, because a panel per entry is a choice about the document rather than a look.

The four letter designs are JSON files too (`Resources/Letters/`), rendered under letters/ above.
