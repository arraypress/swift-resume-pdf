# Examples

Every design this library makes, as a PDF you can open before installing anything.

Generated by the library itself — `WRITE_EXAMPLES=1 swift test --filter ExampleTests` — so none of them can drift from what the code produces. All from the same résumé, so the differences are the design's.

## The fourteen designs

| | |
|---|---|
| [ledger](designs/ledger.pdf) | Single column, ruled sections. The default. |
| [broadsheet](designs/broadsheet.pdf) | Serif, centred masthead. Academic and formal. |
| [timeline](designs/timeline.pdf) | A date rail down the left edge. |
| [margin](designs/margin.pdf) | Section names hung in the left margin. |
| [nocturne](designs/nocturne.pdf) | Light masthead, reversed body. |
| [eclipse](designs/eclipse.pdf) | The whole page reversed, masthead darker still. |
| [bulletin](designs/bulletin.pdf) | Headings as tabs, each with a mark. |
| [marker](designs/marker.pdf) | Highlighter headings. Informal. |
| [slate](designs/slate.pdf) | Twin panels and section tabs. |
| [card](designs/card.pdf) | Every entry on its own panel. |
| [terminal](designs/terminal.pdf) | Monospaced labels and dates, proportional prose. |
| [banner](designs/banner.pdf) | A dark masthead band on a light page. |
| [sidebar](designs/sidebar.pdf) | Two columns behind a tinted rail. A parser cannot read it. |
| [gazette](designs/gazette.pdf) | Serif two columns behind a hairline. A parser cannot read it either. |
